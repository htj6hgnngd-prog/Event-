# VECTA 2.0 — SEO под Яндекс (Москва)

## Источник данных, а не догадки
Основной рынок: Москва, Россия. Поисковая система для проектирования SEO: Яндекс.
Семантическое ядро формировать по Яндекс Вордстату с фильтром **Москва**, затем
проверять посадочные страницы по выдаче Яндекса. **Частоты ещё не получены**,
набор запросов ниже — гипотезы для проверки, не статистика.

| Интент | Предварительные запросы для Вордстата | Посадочная |
| --- | --- | --- |
| Общая фотосъёмка | фотосъёмка мероприятий москва; фотограф на мероприятие | /foto-meropriyatiy/ |
| Общая видеосъёмка | видеосъёмка мероприятий москва; оператор на мероприятие | /video-meropriyatiy/ |
| Комплексная съёмка | фото и видеосъёмка мероприятий; фото видео мероприятие | /foto-video-meropriyatiy/ |
| Конференции | фотограф на конференцию москва; фотосъёмка конференции | /fotograf-na-konferenciyu/ |
| Корпоративы | фотограф на корпоратив; фотосъёмка корпоратива | /fotograf-na-korporativ/ |
| Форумы | съёмка форума; фото видео съёмка форума | /semka-foruma/ |

Не создавать новые страницы под каждую словоформу автоматически.
Только отдельная коммерческая потребность + действительно уникальный контент.
Избегать искусственного повторения ключей в title/H1/первых абзацах.

## Техническая база
- Серверный/статический HTML; русскоязычный контент в исходном HTML.
- Уникальные `title`, `description` и `h1` под намерение каждой страницы.
- `canonical` и Sitemap должны ссылаться на **один подтверждённый публичный домен**.
  Сейчас домен из `astro.config.mjs` — предварительный. Перед релизом проверить.
- Настроить 301 с альтернативных адресов, не заменять редирект только canonical.
- `robots.txt` и `sitemap.xml` положить в public/, зарегистрировать в Вебмастере.
- Структурированные данные: Organization, WebSite, Service, BreadcrumbList.
  Не указывать выдуманный адрес, телефон, правовой статус, рейтинг и отзывы.
- Проверять публичную доступность страниц роботу, HTTP 200, ссылочную структуру,
  изображения, мобильную вёрстку, 404 и редиректы.
- Preview и экспериментальные копии должны быть вне индекса до релиза.

## Яндекс Вебмастер
1. Подтвердить сайт на финальном домене.
2. Указать регион «Москва» только с подтверждающей информацией о географии работы.
3. Передать Sitemap, проверить обход и страницы в поиске.
4. Проверить дубли, ошибки, индексирование и поисковые запросы.
5. Яндекс Бизнес: только если есть подтверждённые сведения об организации,
   соответствующие правилам сервиса.

## Яндекс Метрика
Счётчик подключается **только при наличии собственного ID** через
`PUBLIC_YANDEX_METRIKA_ID` (смотреть `.env.example`).
На сайте заложено событие `telegram_click` для ссылок с
`data-yandex-goal="telegram_click"`, а `portfolio_click` — для портфолио.
В Метрике необходимо создать цели с такими идентификаторами.
**Клик по Telegram не равен полученной заявке** — использовать отдельные
статусы конверсии при появлении проверяемой CRM/lead-формы.
Рассмотреть согласие и политику персональных данных перед запуском измерения.

## Нужно подтвердить до продакшена
- Финальный публичный домен, редиректы и отсутствие защиты SSO.
- Счётчик Метрики, права на аккаунт Яндекс Вебмастера и Вордстат.
- Фактические коммерческие условия, контакты, примеры кейсов.
- Использование собственных фото/видео без проблем с правами.
- Никаких обещаний о позициях в выдаче: результат зависит от индексации и конкуренции.
