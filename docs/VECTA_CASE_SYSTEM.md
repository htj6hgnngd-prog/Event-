# VECTA CASE SYSTEM

Version 1.0

Cases must prove a decision system, not only show attractive media.

## Required case order

1. VISUAL TASK
2. FRAME PLAN
3. COVERAGE
4. OUTPUTS
5. DELIVERY VIEW
6. OUTPUT LENS
7. APPROACH
8. CTA

## Evidence rules

- Do not invent client objectives.
- Do not invent KPI, reach, conversion, revenue or audience numbers.
- If the original brief is unavailable, label the visible editorial intent as VISUAL TASK.
- DELIVERY VIEW describes only a verified delivered or currently presented format.
- Outputs shown in OUTPUT LENS must correspond to real assets.
- Replace generic values with verified client/project facts when the real case package is ready.

## Output Lens

The case interface can switch between verified outputs belonging to the same case.

Current supported views:
- FULL FILM;
- MOTION CUT;
- COVER FRAME.

Future content may add photo series, vertical, interview or backstage only when those assets exist for that project.
