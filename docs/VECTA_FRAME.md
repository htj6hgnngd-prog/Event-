# VECTA FRAME

Version 1.0

VECTA FRAME is the internal planning standard for event photo, video and content production. It exists to ensure that the team does not begin with a list of cameras or deliverables. It begins with the business task and ends with a defined delivery map.

## F / FOCUS

Goal: define why the content exists.

Required inputs:
- business objective;
- primary audience;
- primary channels;
- must-have deliverables;
- content lifespan;
- approval owner.

Output: FOCUS CARD.

A project does not move to RUN while the objective and primary outputs are ambiguous.

## R / RUN

Goal: turn the event programme into a capture map.

Required inputs:
- full schedule;
- critical moments;
- speakers and key people;
- venue zones;
- access restrictions;
- lighting or sound constraints;
- moments that cannot be repeated.

Output: EVENT RUN MAP.

Each critical moment receives a priority:
- MUST CAPTURE;
- SHOULD CAPTURE;
- NICE TO HAVE.

## A / ARCHITECTURE

Goal: design coverage before the team arrives on site.

For every important moment define:
- required media type;
- priority;
- responsible operator;
- camera or position when relevant;
- audio requirement;
- fallback coverage.

Output: COVERAGE MATRIX.

Minimum rule: every MUST CAPTURE moment has an owner and a fallback.

## M / MEDIA

Goal: connect captured material to concrete outputs.

Possible outputs:
- selected photo series;
- master event film;
- highlights;
- interviews;
- vertical cuts;
- PR selects;
- internal communication assets.

For each output define:
- orientation and aspect ratio;
- approximate duration or volume;
- audio requirement;
- source moments;
- editing priority.

Output: MEDIA MATRIX.

## E / EXPORT

Goal: define delivery before post-production starts.

For every output define:
- filename logic;
- folder;
- version;
- platform or destination;
- deadline;
- approval path.

Output: DELIVERY MAP.

## PRE-SHOOT GATE

A project is ready for production only when:
- FOCUS CARD is complete;
- EVENT RUN MAP exists;
- all MUST CAPTURE moments are marked;
- COVERAGE MATRIX has owners;
- MEDIA MATRIX is agreed internally;
- DELIVERY MAP has target formats and destinations.

## OPERATING PRINCIPLE

The event is not treated as one video shoot plus one photo shoot. Photo, video, interviews and vertical content are planned as one coverage system around the same priorities.

FRAME is a planning standard, not a client-facing promise of a specific deliverable count. Final scope remains defined by the approved commercial proposal and production brief.
