# VECTA AGENCY MODE

Version 2.0

Agency Mode has three selectable integration depths.

## CAMERA UNIT
Input: timing, brief, assigned zone.
Team: photo or video unit.
Control: coverage for the assigned area.
Handoff: materials in the agreed structure.

## CONTENT UNIT
Input: timing, brief, output list.
Team: photo + video + content roles as required.
Control: shared coverage map.
Handoff: connected set of materials.

## FULL MEDIA
Input: programme, brief, outputs, visual references.
Team: composition based on the project.
Control: FRAME, MUST CAPTURE, fallback.
Handoff: agreed delivery map.

Agency Mode does not publish white-label, NDA or service-level promises unless they are separately approved as operating rules.
