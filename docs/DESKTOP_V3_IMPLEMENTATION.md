# Desktop editorial v3

Источники: VECTA_DECISIONS_FROM_DIALOGUES.md; выбранные Editorial Flow / Cinematic Immersion; полные страницы image-gen-1(1), image-gen-2(1), непрерывный концепт «Студия / Подход / Запрос». Дополнительно Firecrawl проверил навигацию архива Bottega53: прямые входы в истории и отдельный контакт. Чужой контент не переносится.

## Композиционная система

- Один почти чёрный холст, холодный светлый текст, один красный акцент.
- Крупный VECTA как часть начальной композиции; предметный H1 «Свадебная фотография и кино».
- Асимметричные плоскости медиа, пересечения крупной антиквы и кадров, смещения сторон, небольшие контрапункты-вставки.
- Студия / Подход / Запрос связываются масштабом и переходами плоскостей. Нет отдельных фонов-секций, карточек преимуществ или отзывов.
- Фотографии и видеолупы в одной мозаике. Все плоскости пусты по прямому требованию пользователя.
- Самостоятельные композиции архива, истории, направлений, студии, сравнения форматов и запроса. 11 доступных маршрутов.
- Форматы: фото, фото + Highlight, фото + фильм. Цены не выдуманы. Выбор сохраняется в query-параметре и отмечается в запросе.
- Нативная прокрутка. Одна вступительная анимация, текст доступен без ожидания; reduced motion отключает её.
- Текущая область — desktop 1440 и 1920. Файл design.css и его мобильные правила сохранены; новый визуальный слой editorial-desktop.css предназначен для desktop-review.

## Проверка до публикации

Проверить: все маршруты, один H1, отсутствие медиа, локальные ссылки, фильтры архива, три выбора формата, request без фиктивной доставки, клавиатуру, ошибки JS, геометрию шрифтов и отсутствие обрезанных заголовков. Эта запись не является подтверждением прохождения проверок.
