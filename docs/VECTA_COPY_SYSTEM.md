# VECTA COPY SYSTEM

Version 1.0

Public copy follows one sequence:

RESULT -> MECHANISM -> PROOF -> ACTION

## RESULT

Start with what changes for the client or what remains after the event.

Preferred:
- "Событие заканчивается. Контент работает дальше."
- "Проектируем медиа-результат события."

Avoid opening with adjectives about VECTA.

## MECHANISM

Explain how the result is produced:
- FRAME;
- coverage map;
- one production system;
- output architecture;
- delivery map.

Mechanism copy must name a real production action.

## PROOF

Every major promise must point to one of:
- visible work;
- case asset;
- FRAME operating rule;
- operational control;
- verified project fact.

No invented KPI, clients, awards or performance claims.

## ACTION

CTA describes the next real action:
- собрать карту проекта;
- посмотреть работу;
- открыть Agency Mode;
- передать задачу.

Avoid generic "узнать больше" when a specific next step exists.

## LANGUAGE

- short sentences;
- concrete nouns and verbs;
- premium does not mean complicated;
- Russian explanatory copy, English only for stable production labels;
- no long dash in public site copy;
- no adjectives without evidence.
