# VECTA PROJECT ROUTES

Version 1.0

The public site has two commercial routes.

## BRAND / IN-HOUSE
Audience: marketing, HR, communications and internal teams.
Entry point: business objective and channels.
Primary tool: VECTA FRAME Builder.
Conversion payload: route context + FRAME map + brief.

## AGENCY / PARTNER
Audience: event and communications agencies.
Entry point: existing brief, timing and visual concept.
Primary tool: Agency Mode.
Conversion payload: selected integration depth + brief.

Both routes use the same production core. The difference is where VECTA enters the project.
