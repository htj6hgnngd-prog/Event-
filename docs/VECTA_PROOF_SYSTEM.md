# VECTA PROOF SYSTEM

Version 1.0

VECTA separates trust into two independent layers.

## CREATIVE PROOF

Answers: can the team create a strong result?

Allowed evidence:
- selected work;
- full films;
- photo series;
- actual edits and output variants;
- verified case assets.

## OPERATIONAL PROOF

Answers: can the team control a non-repeatable event?

Current FRAME controls:
- MUST CAPTURE: critical moments are identified before shooting;
- OWNER: each critical moment has a responsible operator;
- FALLBACK: every MUST CAPTURE moment has fallback coverage;
- DELIVERY MAP: versions and destinations are defined before post-production.

## Publication rule

Operational claims on the public site must correspond to a real internal production rule. Creative claims must be supported by visible work. No fake client logos, fake metrics, fake guarantees or invented outcomes.
