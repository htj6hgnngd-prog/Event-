# VECTA Pen Display / Oblique v0.1

Original display study created for VECTA from project-owned geometric path definitions in scripts/build-vecta-lettering.py. No third-party font outlines imported.

Files: vecta-pen-display.ttf and vecta-pen-display.woff2. The SVG word drawings are produced from the same geometry. They provide the primary fixed-composition identity used on the site.

This is an experimental display cut, not a universal body font. Unicode Russian letters are present; some uppercase forms are script-scaled counterparts. Fixed word forms are optically composed and exposed as phrase ligatures. Full uppercase refinement, punctuation, Latin coverage, professional kerning and broad shaping QA remain future font-development work.

The primary Latin VECTA identity in navigation remains unchanged.
