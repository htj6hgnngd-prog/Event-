# VECTA Visual Taste Protocol — how to build a stronger eye

The canon supplies breadth. This protocol turns breadth into judgement. A large folder of saved images is not yet visual literacy; the agent must compare, annotate, test and articulate the decision each reference teaches.

## 1. The operating model: observe → compare → infer → translate → critique

### Observe
Describe only what is visibly or audibly present:
- subject and action;
- camera distance, angle, crop and point of view;
- dominant geometries, lines, shape masses and visual center;
- foreground, midground, background and depth;
- light source, direction, hardness, falloff and shadow shape;
- color relationships and value hierarchy;
- texture, movement, blur and surface;
- gaze, gesture, body tension, social relationship;
- for moving images: shot length, camera movement, cut timing, repetition, sound, silence and transitions;
- for graphics: scale, type, grid, alignment, negative space, image-text hierarchy and how the page/sequence moves.

Do not write “cinematic”, “expensive”, “editorial”, “emotional” or “premium” as if these are visual observations. They are interpretations. Name what makes the effect happen.

### Compare
Choose at least two meaningful contrasts:
- sparse vs. dense;
- frontal vs. oblique;
- open light vs. hard directional light;
- warm/cool relationship;
- centered vs. deliberately off-balance;
- sharpness vs. blur;
- static frame vs. moving camera;
- long duration vs. short cut;
- natural gesture vs. directed pose;
- literal documentation vs. constructed image;
- image-led vs. type-led;
- a quiet detail vs. a wide contextual frame.

Ask what is gained and lost by each choice. Avoid rankings like “A is better” until the target and constraints are clear.

### Infer
Offer a reading of the visual intention only after the observable details. Use cautious language: “the frame creates…”, “this appears to…”, “the sequence seems to…”. Check interviews, production notes or artist statements when intent matters. Do not invent the creator’s intention.

### Translate
Extract one formal principle; do not reproduce the reference image, styling, framing combination or signature look. Translation should be written as an action, such as:
- “Keep an obstruction in the foreground to create a second plane, but use an object from the actual location.”
- “Repeat the same color in two distant frames so the eye links them.”
- “Delay the widest shot until after the audience reaction, to change scale after establishing a human point of view.”
- “Use one brief pause after a sequence of faster cuts.”
- “Let the client’s brand color appear in the environment rather than adding a graphic overlay, if the material genuinely supports it.”

### Critique
Test whether the principle makes the actual VECTA material stronger. If it only makes the material resemble a reference or adds decoration, reject it.

## 2. Reference-card specification

Every new visual reference saved to the living library should include:

- **Exact source:** URL, project/title, creator, date if verified, medium and credit.
- **Inspection status:** profile only; caption only; one image; selected frames; full sequence; full film/film scene; source statement checked.
- **What is visible/audible:** facts, not taste words.
- **Visual mechanics:** framing, layers, geometry, light, color, gesture, texture, spatial relationships.
- **Rhythm mechanics:** duration, cut pattern, movement, repetition, reveal, silence or audio relationship, when relevant.
- **Why it works for a particular goal:** state audience, medium and intent.
- **Principle to transfer:** one sentence that can be implemented differently.
- **Do not transfer:** what would be inappropriate, derivative, off-brand or unsupported in this project.
- **Quality limits:** resolution, inaccessible slides, preview mismatch, missing context, or uncertainty.
- **Tags:** discipline, light, palette, contrast, crop, movement, gesture, production design, typography, emotional temperature, genre and goal.

Do not save a work into a strong visual category based solely on an account bio or a Pinterest-board title. A creator's “style” needs multiple examples from a coherent period or project. One frame can be an example of a decision, not proof of a whole creator's signature.

## 3. Multi-reference rule

For an important brief, don't let one reference dominate. Use a three-source triangle:
1. One reference for composition/light.
2. One reference for sequence/movement/emotional pace.
3. One reference from another medium (painting, sculpture, architecture, graphic design, book design, dance or music).

Prefer references that disagree in useful ways. The aim is to create a new solution that fits the material, not to average three aesthetics into a vague moodboard.

A reference board should have 6–12 well-annotated examples, not 50 unexplained images. Each example must answer a brief-specific question. Use a smaller board for a simple task.

## 4. Visual taste scorecard

Score 0–4 for each dimension (maximum 32). A 0 means absent or counterproductive; 2 means functional but generic; 4 means deliberate, exact and appropriate to the task. Don't score a dimension as if it were fully observed when the source isn't available.

1. **Composition and hierarchy:** one clear visual priority; secondary elements support or intentionally contest it.
2. **Light and tonal design:** light has a role; highlights/shadows and skin/material texture are controlled and appropriate.
3. **Color intelligence:** palette relationships appear intentional, not simply saturated or trendy; color supports subject, scene and mood.
4. **Gesture and spatial relation:** body, environment, object and gaze create a meaningful relationship.
5. **Sequence/rhythm:** changes in scale, density, movement, duration and color shape attention rather than repeating the same beat.
6. **Specificity and originality:** the concept belongs to these exact images and this brief, not any generic photo shoot.
7. **Restraint and omission:** unnecessary frame, word, effect, transition or graphic is removed; chosen emphasis feels earned.
8. **Coherence across the set:** individual elements are distinct yet belong together without looking mechanically uniform.

**Suggested gate:** 24/32 for a moodboard/proposed sequence, with no 0 in composition, specificity or coherence. This score is a creative review heuristic, not a validated metric. Explain weaknesses and revise rather than gaming the score.

## 5. Still-image sequencing

Never sequence by filename, capture order or “best frames” alone. Start with the brief’s intended emotional and informational path. Evaluate each frame's function:
- **Entry:** what stops attention and establishes the visual grammar?
- **Orientation:** what tells us where we are and what kind of world this is?
- **Human anchor:** where do expression, gesture or a relationship pull the sequence together?
- **Detail or interruption:** what introduces a fresh texture, scale or meaning?
- **Expansion/contraction:** when should the viewer move from close to wide, or from activity to stillness?
- **Peak:** what is the strongest moment, and does using it first weaken the build?
- **Release/ending:** what lets the set stop without a forced flourish?

This is a vocabulary of functions, not a mandatory 7-frame structure. A three-image set can be complete. A 25-image set can remain coherent if its rhythm is purposeful.

**Rhythm tests for a carousel:**
- Put all thumbnails in a single overview. Check whether neighboring frames repeat the same silhouette, scale, palette or information.
- Read the sequence with captions hidden.
- Look at just the first and last image. Does the transition create a useful emotional shift?
- Remove 20% of the frames. If the sequence gets stronger, the original version had redundant material.
- Swap two adjacent images. Can you describe a change in pace or meaning? If not, their order may be arbitrary.
- Inspect crop and thumbnail strength separately; the best frame in full resolution may not be the best cover.

## 6. Motion rhythm and edit critique

Assess rhythm at three scales:

**Micro:** cut, action, match, visual emphasis, sound transient, pause.
**Meso:** short phrase or sequence, repetition, variation, shot-size changes, build and release.
**Macro:** overall arc, emotional trajectory, opening promise, middle development, ending aftertaste.

For every candidate edit, record:
- shot count and approximate duration distribution;
- proportion of static / moving camera / subject movement;
- where motion direction changes;
- where shot scale changes;
- whether a cut lands on action, reaction, sound, musical phrase or contrast;
- whether sound leads, follows, bridges or stops;
- the longest held shot and why it earns its duration;
- which moment is the first real emotional or visual change;
- whether the ending resolves, echoes, interrupts or simply stops.

A strong edit doesn't have to follow the beat. Cutting on every beat is not musicality; it can flatten the video into a metronome. The most useful rhythm often comes from tension between soundtrack, body movement, camera movement and shot duration. Silence and imperfect timing are choices when supported by the material.

## 7. Taste, trends and identity

- Trend awareness is useful for vocabulary and context, not as a substitute for judgement.
- Do not assume the most recent or most viral work is the most accomplished.
- Do not confuse high production budget with image quality.
- Do not confuse visual complexity with sophistication.
- Do not confuse low contrast, grain or slow motion with “cinematic.”
- Do not treat beige, black, flash, film emulation, anamorphic flares, handheld movement or typography as a brand identity by themselves.
- Recognize when a stylistic decision is tied to a creator’s larger body of work, cultural context, project, location or collaborators. Isolating it can empty it of meaning.
- Reference a principle; don't copy a recognizable frame, set, pose, grade, shot order, type composition or campaign conceit.
- The VECTA identity should emerge from repeated sound decisions: exact edit, confident framing, sensitivity to real people, disciplined color, clear production craft and the ability to balance editorial control with documentary presence. Use this as a working hypothesis to refine through real projects, not as a fixed preset.

## 8. When producing work for VECTA

Before proposing a carousel, film or post, the agent should privately complete a brief-specific visual thesis:
- **What is this material fundamentally about?**
- **What is its most distinctive visible relationship?**
- **What must the viewer notice first?**
- **What is the intended pace and emotional temperature?**
- **What has to be excluded?**
- **Which three independent references solve three distinct problems?**
- **How will the proposal remain VECTA's own instead of borrowing the reference's signature?**

The delivered response should surface the decisive reasoning in a compact way: visual thesis, selection logic, sequence/pace logic and meaningful alternatives. Avoid long name-dropping.

## 9. Error-recovery protocol

If the agent cannot view a video, image, crop, sequence or original source:
- Say exactly what could and could not be inspected.
- Do not infer visual style from a caption, filename or profile bio.
- Do not treat a search-result thumbnail as the source itself if it may mismatch.
- Fetch an accessible frame, original page, alternate source or contact sheet before concluding.
- If this remains impossible, produce only an evidence-limited text/metadata analysis and label the visual review pending.
- Never mark taste calibration complete solely because the canon file was expanded.

## 10. How the canon should grow

Add only references with a stated reason for inclusion. Avoid endless uncurated lists.
Each new addition should either:
- cover a missing discipline or visual problem;
- challenge an existing assumption;
- show an unusually clear solution to a recurring problem;
- add a culturally or historically different visual language;
- provide a strong counterexample, not only a “best-in-class” example.

Every month, sample the living library: remove duplicates, re-open a portion of sources, check whether links still work, upgrade selected examples from profile-level to actual-work review, and keep uncertain records marked as such.
